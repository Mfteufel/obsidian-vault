# SQL — Structured Query Language

> Lenguaje **declarativo** estándar para gestionar y manipular bases de datos relacionales.

## Características

| Característica | Descripción |
|----------------|-------------|
| **Declarativo** | Describe *qué* se quiere, no *cómo*. Sin estructuras de control propias |
| **Estándar** | Definido por ISO/ANSI. Cada SGBD tiene su dialecto |
| **Relacional** | Basado en tablas, claves primarias y foráneas |

## Sublenguajes

| Sublenguaje | Comandos |
|-------------|----------|
| DDL | `CREATE`, `ALTER`, `DROP` |
| DML | `SELECT`, `INSERT`, `UPDATE`, `DELETE` |
| DCL | `GRANT`, `REVOKE` |
| TCL | `COMMIT`, `ROLLBACK`, `SAVEPOINT` |
