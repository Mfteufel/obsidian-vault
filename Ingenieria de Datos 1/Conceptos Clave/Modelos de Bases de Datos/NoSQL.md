#### Características:

- **Cada registro o documento** en una base de datos NoSQL puede tener una estructura diferente
- **No soportan operaciones JOIN** (no como en SQL)
- **No siempre garantizan completamente** las propiedades ACID (Atomicidad, Consistencia, Aislamiento, Durabilidad)
- Muchas bases de datos NoSQL se adhieren al modelo **BASE** (Basically Available, Soft state, Eventually consistent)
    - Prioriza la **disponibilidad** y **tolerancia a particiones** sobre la consistencia estricta
- **Escalan horizontalmente**: pueden distribuir los datos y las operaciones en múltiples servidores o nodos
- Manejan **volúmenes masivos** (BigData)

#### Clasificación de NoSQL:

1. **Key-Value**: Redis, DynamoDB
2. **Document**: MongoDB, CouchDB
3. **Column-Family**: HBase, Cassandra
4. **Graph**: Neo4j, ArangoDB
