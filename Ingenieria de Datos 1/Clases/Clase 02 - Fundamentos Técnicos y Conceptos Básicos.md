## Componentes y Usuarios de un SGBG

### Componentes del Sistema

- **Hardware**: Procesadores, memoria, almacenamiento secundario
- **Software**: Sistema de gestión de base de datos (SGBD)
- **Personal**: Los usuarios y administradores que interactúan con el sistema

### Tipos de Usuarios

1. **Administrador de la Base de Datos (DBA)**
    - Responsable de la seguridad, mantenimiento y optimización
    - Gestiona backups y recuperación
2. **Diseñadores de la Base de Datos**
    - Definen la estructura lógica y física
    - Establecen relaciones entre datos
3. **Programadores de Aplicaciones**
    - Desarrollan aplicaciones que acceden a la BD
    - Implementan consultas y transacciones
4. **Usuarios Finales**
    - Interactúan con la BD a través de aplicaciones
    - Consultan, insertan, actualizan datos
5. **Data Owner**
    - Propietario de los datos
    - Responsable de la política de acceso y privacidad
