```sql
CREATE TABLE Empleados (
    ID INT PRIMARY KEY,
    Nombre VARCHAR(50)
);
```

**Nota**:

- `INT`: Tipo de dato entero
- `VARCHAR(50)`: Cadena de caracteres hasta 50 caracteres
- `PRIMARY KEY`: Identifica de forma única cada registro
- Se ejecuta a través de SSMS: clic derecho en **Tables** > **New** > **Table**
