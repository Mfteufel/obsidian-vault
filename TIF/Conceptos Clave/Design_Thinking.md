# CC_Design Thinking

> Metodología centrada en el usuario para llegar a un producto: se investiga el problema antes de saltar a la solución.

## Etapas clásicas

| Etapa | Qué se hace |
|---|---|
| **Empatizar** | Entender al usuario y su contexto real |
| **Definir** | Delimitar el problema con claridad |
| **Idear** | Generar posibles soluciones |
| **Prototipar** | Construir versiones rápidas y testeables |
| **Probar** | Validar con usuarios reales y ajustar |

En la materia esto se agrupa en 3 grandes fases: **Research → Ideación → Prototipo**.

## Por qué importa para el MVP

- El [[MVP]] nace de este proceso: no se construye a ciegas
- Sin research previo, el riesgo es resolver un problema que no existe
