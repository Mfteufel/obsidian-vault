## Sistema de Subastas  
  
Este trabajo práctico consiste en desarrollar una **aplicación móvil** que permita participar en subastas en tiempo real.  
  
La aplicación deberá integrarse con el sistema existente de la empresa mediante una **API REST**.  
  
## Objetivo del sistema  
  
Permitir a los usuarios:  
  
- registrarse como postores  
- participar en subastas online  
- realizar ofertas (pujas)  
- ver historial de participación  
- registrar medios de pago  
- proponer artículos para futuras subastas  
  
## Componentes del sistema  
  
El sistema estará compuesto por tres partes principales:  
  
- App móvil  
- API REST  
- Base de datos
