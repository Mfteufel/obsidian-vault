
En esta etapa se comienza a desarrollar el sistema.  
  
El objetivo es tener **al menos el 50% de la aplicación funcionando**.  
  
---  
  
## 1. Backend funcionando al 50%  
  
El backend debe implementar varias funcionalidades del sistema.  
  
Ejemplos:  
  
- registro de usuarios  
- consulta de subastas  
- consulta de objetos  
- registrar una puja  
  
Debe existir conexión con la base de datos.  
  
---  
  
## 2. Frontend funcionando al 50%  
  
La aplicación móvil debe tener varias pantallas implementadas.  
  
Ejemplos:  
  
- pantalla de login  
- lista de subastas  
- detalle de subasta  
- pantalla para realizar pujas  
  
No es necesario que todas las funcionalidades estén completas.  
  
---  
  
## 3. Conexión entre Frontend y Backend  
  
Debe existir **al menos un flujo completo funcionando**.  
  
Ejemplo:  
  
Usuario abre la app  
↓  
Consulta subastas disponibles  
↓  
Selecciona una subasta  
↓  
Realiza una puja  
↓  
El backend valida y registra la puja  
  
Esto demuestra que el sistema funciona **de punta a punta**.  
  
---  
  
## 4. Manejo de errores  
  
El sistema debe manejar situaciones de error.  
  
Ejemplos:  
  
Campos obligatorios vacíos  
Datos inválidos  
Puja menor a la oferta actual  
Problemas de conexión a internet  
  
La aplicación debe mostrar mensajes claros al usuario.  
  
Ejemplo:  
  
"Debe registrar un medio de pago para participar en la subasta".
