En esta etapa la aplicación debe estar **completamente funcional**.  
  
Debe respetar lo diseñado en la primera y segunda entrega.  
  
---  
  
## 1. Aplicación completa  
  
Todas las funcionalidades del sistema deben funcionar correctamente.  
  
Esto incluye:  
  
- registro de usuarios  
- gestión de medios de pago  
- participación en subastas  
- realización de pujas  
- historial de participación  
- gestión de artículos para subasta  
  
---  
  
## 2. Backend desplegado en internet  
  
El backend debe estar disponible en un servidor online.  
  
Esto permite probar los endpoints desde cualquier lugar.  
  
Ejemplos de servicios de despliegue:  
  
- Render  
- Railway  
- Heroku  
- AWS  
  
Los endpoints deben poder probarse desde el navegador o desde herramientas como Postman.  
  
---  
  
## 3. Frontend instalable  
  
La aplicación debe poder instalarse en un dispositivo móvil.  
  
Esto puede realizarse mediante:  
  
- archivo APK  
- instalación directa desde el entorno de desarrollo  
- build de React Native  
  
El objetivo es poder **probar la aplicación en un teléfono real**.
