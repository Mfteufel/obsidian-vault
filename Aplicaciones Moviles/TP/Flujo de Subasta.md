
1. El usuario inicia sesión.

2. Consulta las subastas disponibles.

3. Selecciona una subasta.

4. Visualiza:

- item actual
- oferta más alta
- historial de pujas

5. Realiza una puja.

6. El backend valida:

- que el usuario tenga medio de pago
- que la puja sea válida
- que la subasta esté abierta

7. Si la puja es válida:

- se registra
- se actualiza la mejor oferta
- se notifica a los demás usuarios

8. Cuando termina la subasta:

- el último postor gana
- se genera la venta
