Son apps que corren en el navegador. Básicamente un sitio web optimizado para celular.

- **Tecnologías**: HTML, CSS, JavaScript (React, Vue, Angular, etc.)
- Se accede por URL
- Responsive design para adaptarse a cualquier pantalla

**Ventajas:**

- Un solo código para todos los dispositivos
- Desarrollo más rápido y económico
- Fácil de actualizar (sin pasar por App Store)
- Cualquiera con navegador puede usarla

**Desventajas:**

- Rendimiento más lento que nativas
- Acceso limitado a características del dispositivo
- Necesita conexión a internet
- No aparece en app stores (menos visibilidad)
