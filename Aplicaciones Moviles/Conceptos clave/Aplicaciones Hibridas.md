Es lo de "lo mejor de los dos mundos". Es una app web empaquetada como nativa usando frameworks como **React Native** o **Flutter**.

- **Tecnologías**: React Native, Flutter, Ionic, Cordova
- Un código que funciona en iOS y Android
- Se distribuye por app stores

**Ventajas:**

- Un solo código para ambas plataformas (ahorro de tiempo y plata)
- Mejor rendimiento que web pura
- Acceso a funcionalidades nativas del dispositivo
- Se puede distribuir en app stores

**Desventajas:**

- Rendimiento no es tan bueno como nativo puro
- Dependés del framework (si te deja hacer algo, lo haces; si no, quilombo)
- Comunidad más chica que nativas puro
