- Iniciaremos con una pantalla donde el usuario podrá ingresar su nombre y elegir si desea jugar al Ta-Te-Ti con cruces o círculos​
    
- Presionando el botón de comenzar pasará a la siguiente actividad donde desarrollaremos el juego​
    
- Si tipeamos “juan” y no seleccionamos con que símbolo desea jugar, le asignamos cruces.​
    
- Si no le asignamos un nombre lo llamaremos extraño
  
  
## Segunda actividad

- Iniciaremos con una pantalla donde se encuentra el nombre ingresado y la selección.​
    
- A continuación aparece el tablero donde según sea el jugador o la maquina aparecerá el símbolo correspondiente.​
    
- El juego controlara que no se pueda cambiar una casilla una vez presionada y la alternancia de turnos.​
    
- Cuando el juego termine deberá mostrar el nombre del ganador, el jugador, la maquina o empate.​
    
- El volver a jugar reinicia el juego.​
