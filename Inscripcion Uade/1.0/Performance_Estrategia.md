  
El sistema debe soportar miles de estudiantes simultáneamente.  
  
## Técnicas utilizadas  
  
Cache Redis para consultas frecuentes.  
  
Índices en PostgreSQL.  
  
Paginación en consultas.  
  
Read replicas para lecturas intensivas.  
  
CDN para frontend.  
  
## Objetivo  
  
Tiempo de respuesta de API < 300 ms
