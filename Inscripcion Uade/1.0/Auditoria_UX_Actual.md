
## Problemas detectados

### UI Fragmentada
El sistema actual utiliza múltiples modales que interrumpen el flujo del usuario.

### Falta de contexto
El estudiante no puede ver su horario completo mientras selecciona materias.

### Búsqueda obligatoria
Los usuarios deben buscar materias manualmente para ver comisiones.

### Ansiedad por cupos
El sistema muestra advertencias de disponibilidad sin mostrar cupos reales.

## Consecuencias

- proceso lento
- frustración del usuario
- errores de inscripción
