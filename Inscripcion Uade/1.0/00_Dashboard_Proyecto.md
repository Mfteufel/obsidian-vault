# Smart Enrollment Dashboard – UADE

Sistema de inscripción universitaria optimizado para alta concurrencia.

## Objetivo
Rediseñar el sistema de inscripción de materias de UADE para reducir fricción en el proceso y soportar miles de usuarios simultáneamente.

## Problemas actuales

- Interfaz fragmentada basada en modales.
- Alta carga cognitiva para el usuario.
- Falta de visualización clara de horarios.
- Cupos visibles solo después de buscar.
- Lentitud del sistema en momentos de alta demanda.

## Propuesta

Crear un **Smart Enrollment Dashboard** que permita:

- explorar materias fácilmente
- visualizar horarios en tiempo real
- detectar conflictos automáticamente
- ver disponibilidad de cupos
