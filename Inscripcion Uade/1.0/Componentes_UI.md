## Selector de materias  
  
Permite explorar materias del plan de estudios.  
  
## Explorer de comisiones  
  
Lista las comisiones disponibles de cada materia.  
  
Muestra:  
  
- docente  
- horario  
- cupos disponibles  
- Poder seleccionar varios dias

- mañana  
- tarde  
- noche  
  
## Calendario dinámico

- materias seleccionadas  
- conflictos horarios
