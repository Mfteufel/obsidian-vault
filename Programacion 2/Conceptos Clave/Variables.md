# CC_Variables

> Java es **estáticamente tipado**: el tipo de cada variable se conoce en tiempo de compilación y no puede cambiar después.

## Reglas clave

- Toda variable **debe declararse con su tipo** antes de usarse.
- El tipo de una variable **no puede cambiar** durante la ejecución del programa.
- Una variable es un área de memoria reservada — su nombre es el nombre de esa asignación.

## Sintaxis

```java
<tipo> <nombre de variable>;
```

**Ejemplo:**

```java
int contador;
```

## Varias variables del mismo tipo

```java
<tipo> <nombre1>, <nombre2>;
```

**Ejemplo:**

```java
int contador, cantidad;
```

## Declarar y asignar en un solo paso

```java
int contador = 0;
char c = 'f';
```
