# CC_Operadores

> Java tiene tres grandes grupos de operadores: aritméticos, relacionales y lógicos.

## Aritméticos

| Operador | Significado |
|---|---|
| `+` | Suma |
| `-` | Resta |
| `*` | Multiplicación |
| `/` | División |
| `%` | Resto (módulo) |
| `++` | Incremento unitario |
| `--` | Decremento unitario |

## Relacionales (comparadores)

| Operador | Significado |
|---|---|
| `>` | Mayor que |
| `<` | Menor que |
| `>=` | Mayor o igual |
| `<=` | Menor o igual |
| `==` | Igual a |
| `!=` | Distinto de |

## Lógicos

| Operador | Significado |
|---|---|
| `!` | Negación |
| `\|\|` | Disyunción (OR) |
| `&&` | Conjunción (AND) |
