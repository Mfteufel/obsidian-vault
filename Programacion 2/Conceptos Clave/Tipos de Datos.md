# CC_Tipos de Datos

> En Java todo dato tiene un tipo. Se dividen en **primitivos** y **no primitivos**.

## Primitivos vs no primitivos

| Categoría | Qué incluye |
|---|---|
| **Primitivos** | Booleanos, Numéricos (enteros y reales), Caracteres |
| **No primitivos** | Cadenas (String), Arreglos, Otros objetos |

## Tabla de tipos primitivos

| Tipo | Tamaño | Rango | Valor por defecto |
|---|---|---|---|
| `boolean` | 1 bit | `false` → `true` | `false` |
| `byte` | 1 byte | -2⁷ → 2⁷-1 | `0` |
| `short` | 2 bytes | -2¹⁵ → 2¹⁵-1 | `0` |
| `int` | 4 bytes | -2³¹ → 2³¹-1 | `0` |
| `long` | 8 bytes | -2⁶³ → 2⁶³-1 | `0L` |
| `float` | 4 bytes | ilimitado | `0f` |
| `double` | 8 bytes | ilimitado | `0d` |
| `char` | 2 bytes | `\u0000` → `\uffff` | `\u0000` |

## Enteros vs reales

- **Enteros:** `byte`, `short`, `int`, `long`
- **Reales:** `float`, `double`
